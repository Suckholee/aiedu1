# Firebase 공유

공유 데이터는 `gahoseokho` 프로젝트의 `aieduPlatforms/main` 하위 컬렉션에 저장합니다. 로컬 원본과 이전 시점 백업은 `.local-data`에 보존합니다. 다시 이전해도 기존 공유 공간을 덮어쓰지 않습니다.

Google 로그인 사용자는 홍보 캘린더의 초안·예정·완료 글을 공유하고 편집합니다. 비로그인 방문자는 게시 완료 글과 공개 교육과정만 봅니다. 신청 및 후기는 인증된 본인 이메일로 작성하며, 학습 진행은 본인 내역만 변경합니다. 연락처·메모·운영 기록은 관리자만 전체 조회합니다. 현재 공유 편집 범위는 모든 인증된 Google 사용자입니다.

관리자는 Firebase Auth의 `admin: true` custom claim 또는 서버 환경변수 `PLATFORM_ADMIN_EMAILS`(쉼표로 구분)로 지정합니다. 클라이언트 users 문서의 role 값은 권한 판단에 사용하지 않습니다. 서버는 Firebase ID 토큰을 검증합니다.

파일 업로드는 관리자 전용이며 Firebase Storage에 저장합니다. 자료 링크는 승인된 수강생에게 전달됩니다. 다운로드 링크를 전달받은 사람은 파일에 접근할 수 있습니다.

변경 사항은 다른 기기에서 최대 5초 후 표시됩니다. 게시 완료 상태는 실제 게시 기록이며 외부 SNS 자동 발행 기능은 아닙니다. 배포 서버에도 Firebase 공개 설정과 Admin 서비스 계정 환경변수가 필요합니다. 로컬 주소는 다른 사람에게 공유할 배포 주소가 아닙니다.

이전: `pnpm migrate:firebase`. 로컬 전용 기존 통합 테스트는 Firebase 전환 이후 실행하지 않습니다.
