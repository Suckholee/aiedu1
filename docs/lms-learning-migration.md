- 브라우저의 기존 정산·장부·CRM 기록은 그대로 남긴다. 통합 화면에서 기존 CRM으로 연결한다. 수강생 화면은 서버 학습 기록과 이 기기의 이전 신청 기록을 구분한다. 기기 정산 기록을 검증 없이 수강 승인·결제 증빙으로 자동 이전하지 않는다.

## 운영 동작

1. 과정 공개 및 기수 모집 중 상태에서 로그인 회원이 신청한다. 금액은 DB 기수에서 읽고, 소속·신청 메모·연락처를 서버에 보관한다.
2. 신청·승인·수료 인원은 좌석을 차지한다. 대기자는 좌석을 차지하지 않는다. 신청·상태 변경과 기수 정원 수정은 같은 트랜잭션 잠금을 사용한다. 같은 회원의 중복 신청은 기존 신청 번호를 반환한다.
3. 담당자는 신청·대기·승인·반려·취소·수료·수강권 회수를 관리한다. 수강생은 신청·대기 상태에서만 본인 신청을 취소한다. 취소·수강권 회수는 금전 환불을 실행하지 않는다.
4. 기수별 수업 회차를 추가하고 출석·지각·결석·공결을 개별 또는 최대 200명 일괄 저장한다. 일괄 요청에 잘못된 수강생이 있으면 전체를 롤백한다.
5. 차시별 문서·영상·실시간 수업·실습·평가를 구성한다. 담당자는 0~100% 진도를 확인·정정한다. 수강생은 본인 차시 완료를 표시하며 평가 진도는 담당자만 기록한다. 자동 영상 시청 시간 측정은 구현하지 않았다.
6. 회차·차시는 삭제 대신 보관·복원하며 기존 출결과 진도를 보존한다. 회차 복원 시 일정 충돌도 검사한다.
7. 기본 수료 조건은 필수 차시 모두 완료와 모든 활성 회차의 출석·지각·공결이다. 차시·회차가 하나도 없는 기수는 수료 처리하지 않는다. 자동 수료증 발급·평가 점수 기준은 다음 단계다.
8. 만료·회수된 수강권에는 학습 링크를 주지 않으며 진도 쓰기를 거부한다. 이전 신청 이력과 본인 출결·진도 기록은 조회 가능하다.

## 권한과 저장소

- `/api/lms/learning`의 조회·명령은 검증한 Supabase 세션과 활성 회원 ID를 기준으로 한다. 이메일만으로 수강신청을 소유 처리하지 않는다.
- 관리자·교육 운영 담당자만 타인 신청·회차·차시·출결·운영 메모를 관리한다. 회계 권한만으로 학습을 수정할 수 없다.
- DB 명령 함수는 service_role만 실행한다. 브라우저 공개 키에 직접 쓰기 권한은 없다. 학습 링크·운영 메모·원본 이전 payload는 직접 공개 SELECT 대상에서 제외한다.
- API에는 같은 Origin 검사를 적용하고 조회 응답은 private/no-store로 반환한다. 로그아웃·계정 전환 시 이전 회원 데이터가 남지 않도록 요청 세대를 확인한다.
- 기존 자료 파일 자체는 Firebase Storage에 남는다. 링크·차시 메타데이터만 Supabase가 기준이다. 이미 발급된 외부/Firebase 다운로드 URL 자체의 회수와 Supabase Storage·서명 URL 전환은 다음 단계다.
- 결제·환불·정산은 이번 학습 상태와 별도로 기존 기록을 유지한다. 결제 수단 선택을 결제 완료로 간주하지 않는다. 신청 화면의 예시 계좌·자동 취소 안내를 제거하고 담당자 수납 안내로 표시했다.

## 검증

- 기존 스키마·RLS·역할 검증 74개 통과.
- 새 학습 명령 검증 69개 통과: 좌석·중복·본인 소유권·만료·교차 기수·일괄 저장 롤백·진도 정정·수료·보관·비공개 열 권한 포함. 좌석 경합 검사는 격리 PGlite에서 여러 요청을 실행한 결과이며 운영 부하 테스트를 의미하지 않는다.
- 실제 Supabase에서 신청 → 승인 → 회차 출결 일괄 저장 → 차시 진도 → 수료 흐름을 검증했다. 전체 테스트 트랜잭션은 롤백하여 테스트 회원·과정·신청을 남기지 않았다 (`scripts/test-lms-learning-hosted.sql`). 기존 회원 8명 유지 확인.
- 로컬 프로덕션 HTTP 검증 32개 통과. 기존 관리자 신원으로 학습 DTO·입력 검증·CSRF·기존 회원 조회를 확인하고 테스트 세션만 종료했다.
- Next.js webpack 프로덕션 빌드 및 TypeScript 검사 통과. Vercel 기본 Turbopack 빌드도 통과했다. 운영 HTTP 32개 및 기존 관리자 신원의 실제 학습 DTO·입력 검증·CSRF·회원 조회도 통과했다.
