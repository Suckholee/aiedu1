# 현재 저장소 안내

Firebase 공유 저장소로 이전했습니다. 아래 내용은 이전 로컬 구현 기록입니다. 현재 권한과 실행 방법은 [Firebase 공유](firebase-sharing.md)를 참고하세요.

# 로컬 교육플랫폼

실행: `pnpm dev:local` 또는 `node node_modules/next/dist/bin/next dev --hostname 127.0.0.1 --port 3000`

주소: http://localhost:3000 (127.0.0.1의 페이지 요청은 localhost로 이동)

## 연결된 운영 흐름

1. `/admin/courses`: 과정, 정원, 가격, 강사, 교육일, 시각, 장소, 커리큘럼, 공개 여부를 저장합니다. 저장한 과정은 홈, 교육과정 목록, 상세, 캘린더에 반영됩니다. 같은 강사 또는 장소의 일정 충돌을 검사합니다.
2. `/admin/promotions`: 배너 문구, 링크, 게시 기간, 순서, 공개 여부를 저장합니다. 게시 기간은 한국 날짜 기준입니다.
3. `/courses`: 이름, 이메일, 연락처로 로컬 테스트 신청을 접수합니다. 중복 신청과 정원 초과를 서버에서 검사하고 정원을 차감합니다.
4. `/admin/crm`: 신청 승인·반려 및 상담 기록을 저장합니다. 반려 시 좌석을 반환합니다.
5. `/admin/operations`: 과정에 자료 링크 또는 파일을 등록하고 출석·수료·테스트 환불·후기 공개를 관리합니다. 환불은 기록과 좌석만 변경하며 결제 서비스 요청은 발생하지 않습니다.
6. `/my-learning`: 신청 이메일로 신청 상태, 자료, 학습 진행을 조회합니다. 승인된 신청만 완료 기록을 남길 수 있습니다. 출석 확인 후 관리자가 수료 처리하면 수료 확인서를 인쇄할 수 있습니다.
7. `/reviews`: 승인된 신청 이메일로 후기 작성 후 관리자 검토를 거쳐 공개합니다. 공개된 후기와 평점은 홈·과정 상세에도 연결됩니다.
8. `/`와 `/calendar`: 날짜별 홍보글을 월간·목록으로 조회합니다. 날짜, 시각, 채널, 초안·게시 예정·게시 완료 상태, 본문, 이미지, 게시 링크, 담당자를 저장하고 날짜 이동·복사·검색·필터를 지원합니다. 초기 4개 글은 예시 교육과정에서 작성한 초안입니다. 외부 채널 게시 완료 기록에는 실제 게시 URL이 필요합니다. 게시 예정은 일정 기록이며 자동 게시가 아닙니다.
10. `/calendar/education`: 기존 교육일 조회·분야/개인 필터·ICS 내보내기를 제공합니다.
11. `/education`: 기존 교육플랫폼 소개·배너·추천 강의·후기를 제공합니다.
9. `/admin`: 공통 데이터 기반 집계와 변경 이력을 표시합니다.

데이터는 `.local-data/platform.json`, 업로드 파일은 `.local-data/files/`에 저장됩니다. 새로고침·로컬 서버 재시작 후 유지됩니다. 탭 간 변경은 5초 간격 또는 포커스 복귀 시 반영됩니다. 이 디렉터리는 Git 추적 대상이 아닙니다.

## 사용 범위

공통 API는 개발 모드의 로컬 호스트에서만 동작합니다. 로컬 검증을 위해 관리자 기능은 로그인 없이 사용할 수 있고 이메일 조회는 신원 인증이 아닙니다. 운영 서비스로 배포하려면 서버 인증·역할별 권한과 사용자별 조회 제한을 구현해야 합니다.

현재 과정 데이터는 예시 과정으로 초기화됩니다. 가격·정원·일정은 관리자에서 수정할 수 있습니다. 브라우저 검증용 `browser-test@example.com` 신청과 첫 과정의 실습 자료 링크가 포함되어 있습니다.

PPT 명세 85개 항목 전체를 구현한 상태는 아닙니다. 실제 PG 결제·부분 환불·가상계좌, 문자·이메일·알림톡, 전자세금계산서, PPT 자동 PDF 변환, 가입·계정 통합·RBAC, 대기자 자동 승격, 강사료 정산, 세부 동의 이력·운영 모니터링, 제휴사 편집은 후속 구현 및 외부 연동이 필요합니다. 현재 자료는 PDF 브라우저 열람과 원본 파일 다운로드를 지원합니다.

## 검증

로컬 서버 실행 후 `pnpm test:platform`을 실행합니다. 테스트는 정원 1명의 동시 신청, 중복 방지, 승인·자료·진도·출석·수료·후기·환불, 일정 충돌, 배너, 업로드·다운로드, 외부 출처 차단, 주요 12개 페이지 응답을 검증합니다. 실행 전 데이터 파일을 백업하고 종료 시 복구합니다. 테스트 중에는 같은 데이터에 실제 작업을 저장하지 마세요.

검증 결과: TypeScript 타입 검사, 연동 테스트, Webpack 기반 Next.js 프로덕션 빌드 통과. 기본 Turbopack 빌드는 이 실행 환경의 내부 포트 제약으로 실패했으며 Webpack 빌드로 대체 검증했습니다.

홍보 캘린더 검증: `pnpm test:promotions` (로컬 서버 실행 필요). 등록·수정·날짜 이동·저장 유지·외부 게시 링크 검증·날짜와 과정 검증을 포함합니다.

Google 로그인: Firebase 허용 도메인에 localhost가 등록되어 있습니다. 로컬 페이지는 localhost로 통일합니다. Gmail 주소 직접 입력은 계정 인증이 아닌 로컬 게스트 프로필입니다.
