STEP 07

공용 자동생성 글 받기

확장 프로그램을 열고 새로고침 버튼을 누릅니다. 공용 자동생성 글 목록에서 사용할 글을 선택하고 제목과 본문을 확인합니다. 확장 프로그램 자체의 로그인은 필요하지 않습니다. 설치 후에는 기존 웹페이지를 새로고침하세요.

자주 막히는 부분

이전 2.7.1 버전을 설치했다면?

새 2.7.2 ZIP을 받아 압축을 풀고, chrome://extensions/에서 이전 수강생용 확장을 제거한 뒤 새 폴더를 불러오세요. 압축해제 설치는 자동 업데이트되지 않습니다.

로그인하지 않아도 글을 받나요?

확장 프로그램 자체의 별도 로그인 없이 자동생성된 공용 글을 받아볼 수 있습니다. Chrome이 실행 중이면 공용 자동생성 글을 주기적으로 확인합니다. 수강생용 2.7.2는 공용 자동생성 글 목록을 조회합니다. 작성자의 계정이나 Chrome 프로필에 묶이지 않습니다. 네이버에 글을 작성하려면 네이버 로그인은 필요합니다.

manifest.json 오류가 나요

압축을 풀었는지 확인하고 manifest.json이 바로 들어 있는 안쪽 폴더를 선택하세요.

아이콘이나 글이 보이지 않아요

프로그램이 켜져 있는지 확인하세요. 설치 후 실습 페이지를 새로고침하고 같은 Chrome 프로필에서 동기화를 다시 진행한 뒤 프로그램을 다시 열어보세요.

개발자 모드가 없거나 설치가 막혀요

Chrome 일반 창인지 확인하세요. 회사·학교의 관리 기기라면 담당자에게 설치 허용 여부를 문의하세요.

설치 폴더를 지워도 되나요?

설치에 사용한 압축 해제 폴더를 유지하세요. 파일을 삭제하거나 이동하면 다시 불러오기가 필요할 수 있습니다.

오늘의 완료 기준

설치 카드 확인 → 아이콘 열기 → 내 글 수신 → 글쓰기 창 입력 확인.

체크 기록은 현재 브라우저에만 저장됩니다. 설치 중 요청되는 사이트·클립보드 권한은 내용을 읽고 확인하세요. 실습은 임시저장 모드로 진행합니다.
